# PBK Investor Demo Script

Use this as a 5-minute walkthrough for investors, operators, or strategic partners.

## 0:00 - Positioning

"PBK Command Center is an approval-gated AI operating system for wholesale real estate. Ava handles voice, follow-up, memory, and deal execution. Rex handles research, strategy, and plain-English reporting."

## 0:30 - Lead Portal

Show:

- Lead list
- Lead status
- Selected lead details
- Strategy notes in the Lead Portal

Say:

"The system keeps strategy where operators work leads, not hidden in an agent console."

## 1:15 - Deal Analyzer

Show:

- Path strategy
- Cash/CF/MT/land routing
- CoC calculator for CF/MT
- Live tracker outputs

Say:

"PBK does not just produce a number. It explains the path, the risk, and the next approval-gated action."

## 2:00 - Founder Approval Board

Show:

- Pending approval
- Plain-English wording
- No raw JSON required

Say:

"Ava can move fast, but provider writes stay supervised. The operator sees exactly what is being proposed before SMS, email, calls, or contracts go out."

## 2:45 - Brain Page

Show:

- Ava/Rex brain summary
- Readable summaries
- Memory and feedback loop

Say:

"Every approval, rejection, correction, and conversation becomes structured learning. Routine lead learning is frictionless. Strategic policy changes are protected."

## 3:30 - Voice

Show:

- Ava avatar
- Browser mic readiness
- Transcript panel

Say:

"The voice layer uses Deepgram for real-time speech-to-text and ElevenLabs for spoken response. The phone path is approval-gated and ready for proof calls."

## 4:15 - Live Web Search

Ask Rex:

"What are current mortgage rates and how should that affect creative finance conversations?"

Say:

"Rex uses live OpenAI web search for current market information. If provider quota fails, PBK falls back to its own Brain and labels the answer clearly."

## 4:45 - Close

Say:

"This is not a generic chatbot. PBK is a supervised, memory-driven wholesale operating system that can qualify leads, reason through deal paths, prepare approvals, learn from outcomes, and keep the founder in control."

## Do Not Demo Yet

Avoid live provider sends during investor demos unless intentionally staged:

- Real SMS
- Real email sends
- Real outbound calls
- Real DocuSign envelopes

Use approval previews unless the demo is explicitly a production proof.
