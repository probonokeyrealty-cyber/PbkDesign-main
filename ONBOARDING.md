# PBK Team Onboarding

This guide helps a new PBK operator understand how to use the Command Center safely.

## What PBK Does

PBK Command Center helps the team:

- Intake and qualify seller leads.
- Analyze cash, creative finance, mortgage takeover, and land paths.
- Prepare follow-ups and approval requests.
- Generate and send contract packages through approved provider paths.
- Let Ava/Rex learn from real conversations and approvals.

## Daily Operator Flow

1. Open the PBK Command Center.
2. Review the Lead Portal and Outreach Campaigns.
3. Use the Deal Analyzer to confirm the best path.
4. Check the Founder Approval Board for pending decisions.
5. Approve only actions you understand.
6. Escalate uncertain, destructive, or high-dollar decisions.

## Approval Rules

Routine lead work does not require the protected admin passcode:

- Lead notes
- Seller preferences
- Follow-up timing
- Deal-specific objections
- Campaign review notes
- Call outcomes

Strategic brain changes do require protected admin control:

- Company policy
- Pricing rules
- Script changes
- Contract defaults
- Compliance rules
- Creator or identity changes
- Memory deletion or overwrite

## Working With Ava

Good examples:

- "Ava, remember this seller prefers morning callbacks."
- "Ava, summarize the last call in plain English."
- "Ava, create a follow-up draft for approval."
- "Ava, what path should this lead be in and why?"

Do not ask Ava to bypass approval mode. Provider writes should remain supervised.

## Working With Rex

Rex is the research and strategy brain.

Use Rex for:

- Market research
- Web search
- Campaign strategy
- Deal path reasoning
- Plain-English summaries
- Investor demo explanations

If live web search is temporarily unavailable, Rex will fall back to PBK Brain and label the answer clearly.

## Voice Use

Browser voice is enabled and uses Deepgram for speech-to-text.

Before using the mic:

- Confirm the private bridge key is saved in Settings.
- Use a quiet room for best transcription.
- Do not speak provider secrets aloud.

## Safety Culture

PBK is built for speed, but the correct launch posture is supervised:

- SMS, email, calls, and contracts remain approval-gated.
- Destructive actions require review.
- Strategic memory updates require admin control.
- If Ava/Rex are uncertain, they should ask for clarification.
