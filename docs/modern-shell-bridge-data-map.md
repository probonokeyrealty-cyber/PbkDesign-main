# Modern Shell Bridge Data Map

Purpose: every modern-shell or legacy-layout port must declare its data source before it ships. If a component cannot point at a real OpenClaw/Mastra bridge endpoint or a deliberately local-only source, it is marked **needs Mastra wiring**.

Checked source files:

- `src/app/utils/runtimeBridge.ts`
- `src/app/hooks/useRuntimeSnapshot.ts`
- `scripts/openclaw-local-server.mjs`
- `src/app/shell/*`
- `src/app/routes/*`
- `src/app/components/{CallFloorPanel,CallModeTab,DocumentPdfPanel,ScriptPanel}.tsx`

## Shared Runtime Feed

Components using `useRuntimeSnapshot()` are fed by this polling bundle:

| Feed             | Endpoint                         | Exists | Notes                                                                                                                                                                  |
| ---------------- | -------------------------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Runtime snapshot | `GET /state` or `GET /api/state` | Yes    | Includes `settings`, `approvals`, `activity`, `leadImports`, `analyzerRuns`, `calls`, `messages`, `contracts`, `adminTasks`, `adminAudit`, and related runtime arrays. |
| Quotas           | `GET /api/quotas`                | Yes    | Used for provider quota cards/status in settings-like surfaces.                                                                                                        |
| Tooling status   | `GET /api/tooling/status`        | Yes    | Used for repo/tooling/provider readiness. Also currently carries some agent/tool summary data used by Agent Fleet and Command Center.                                  |

## Porting Rule

Before porting a legacy visual component into the modern shell:

1. Name the exact endpoint or local deterministic source.
2. Confirm the endpoint handler exists in `scripts/openclaw-local-server.mjs`.
3. Confirm the frontend helper exists in `src/app/utils/runtimeBridge.ts` or add one.
4. If the endpoint/tool is `/invoke`, list the required `toolName` and treat tool registration as part of the contract.
5. If no endpoint exists, label the component **needs Mastra wiring** and do not ship a mock payload.
6. Empty states must describe the real state: “no approvals waiting,” “bridge returned no rows,” or “Mastra wiring needed.”
