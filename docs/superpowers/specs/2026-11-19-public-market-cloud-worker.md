# Public market cloud worker

The founder selected **Public market brief** as the first E2B job. Build it on the existing staging branch and preserve production, the one-tool Composio inventory profile, the original PBK design, Rex in Brain and the existing approval queue.

Render remains the agent supervisor and state authority. The bridge gathers a public market search summary/citations through a separate pinned Composio session exposing only `COMPOSIO_SEARCH_WEB`, with no connected accounts or generic execution surfaces. Private Brain/native model fallback is prohibited. A temporary E2B worker runs fixed checked-in code to prepare the evidence brief and source coverage information. This is not moving Rex's model inference into E2B, an autonomous browsing agent, verified underwriting or legal/financial advice. No lead/contact/CRM fields, model credentials or master keys enter the sandbox.

`Rex prepare cloud market brief for <market>` queues a fixed provider/admin approval with a sealed market payload. It performs no search or sandbox work at preparation, page load or status refresh. Only approving that exact task through the existing queue may run it. Reject forged tasks, payload overrides, consumed approvals, unsupported agents/operations and simultaneous jobs. Persist the started/consumed marker before any provider call; restart must not replay a started job.

Use the public E2B SDK rather than its internal constructor or a custom process protocol. This needs a separately approved backend E2B key; never recover/copy the provider key from the Composio connection or browser/CLI caches. The new runner is default-off. Create one `base` sandbox per approved job with a60-second lifetime, kill-on-timeout, internet/public traffic disabled, anonymous job metadata and an idempotency key. Write only a bounded public evidence JSON and fixed program. Never interpolate user text into a shell command, accept caller code/URLs/env/template/IDs, or pass the backend key to the workload. Always kill in finally; report cleanup uncertainty truthfully.

Market labels contain letters/punctuation only, maximum80 characters. Search uses a fixed public residential-market query and only a bounded answer plus clean HTTPS source links may cross the sandbox boundary. Refuse missing live evidence or credential-shaped content. The brief clearly labels source/search limitations and never invents missing publication dates or financial values. Worker output must match the job/input digest and approved citations before persistence.

Store the job/result through `browserResearchJobs` and existing admin execution history. A separate permanent Postgres claim table prevents stale snapshot retries from restoring an unused approval; its transaction-scoped global lock and five-minute lease prevent restart overlap. File-backed claims exist only for isolated tests. Generic research callbacks and admin creation cannot overwrite or impersonate sealed market records. Show E2B status/results in the existing Brain panel and Settings; a new request/retry creates a fresh approval, never starts a job directly. This increment is single-instance staging only; production promotion/multi-instance scheduling is separate.

Alternatives: Composio lifecycle plus direct envd access would depend on lower-level/internal SDK details; enabling broad workbench/code tools would exceed the current inventory scope. The public SDK with a dedicated server-only key is the chosen implementation decision. No new key, sandbox or deployment is authorized merely by preparing this code; present the tested change and exact activation scope first.
