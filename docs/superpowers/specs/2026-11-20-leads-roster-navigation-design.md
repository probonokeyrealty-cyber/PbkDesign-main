# PBK Leads roster navigation

The next daily-workflow update makes it easier to open the right seller workspace from the Leads roster. The founder chose this ahead of changes to navigation within the lead.

Give each row a visible **Open lead** link beside the seller identity, with room for the address to wrap and the link to move below it on narrow phones. Selecting the seller still opens the quick preview. The link uses the row’s canonical ID. **Back to leads** restores the roster search, filter, page, scroll, and focus on the originating lead.

Keep the original PBK shell, row summaries, quick actions, and responsive layout. Use the existing workspace route and saved evidence. Browsing to a lead uses existing CRM reads. Property refresh and provider actions retain their explicit triggers.
